Como criar o repositório e o token (leva ~2 min)

Passo 1 — criar o repositório da nuvem (só uma vez):

  1. Abra github.com/new logado na sua conta.
  2. Em Repository name escreva: lepus-backup.
  3. Marque Private (fica só nos seus olhos).
  4. Toque em Create repository. Pronto, anote: seuusuario/lepus-backup.

Passo 2 — criar o token (a chave que deixa o app gravar lá):

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Token name escreva: lepus-backup. Em Expiration, escolha 90 dias ou mais.
  3. Em Repository access, escolha Only select repositories e marque lepus-backup.
  4. Desça até Permissions → Repository permissions, procure Contents e marque Read and write.
  5. Toque em Generate token, copie o código (começa com github_pat_…) e cole no campo acima.

Esse token dá acesso apenas ao repositório de backup — nada mais da sua conta. Se um dia ele vazar, basta apagar lá em Settings → Developer settings.
